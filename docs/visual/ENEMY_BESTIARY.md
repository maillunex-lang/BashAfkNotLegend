# ENEMY_BESTIARY.md — бестиарий (проектные предложения)

Цель покрытия: **24** рядовых + **12** элитных + **6** боссов = 42.  
Мифологические имена (Шурале, Убыр, Аждаха) = художественная интерпретация, не канон фольклора (`fiction: true`).

Статус VIS-00: каталог-каркас; спрайты **не** массово генерируются до утверждения арт-направления.
