# ANIMATION_SPEC.md

**Правило:** статичный PNG / CSS-движение ≠ покадровая анимация. Mock только с явной меткой.

Приоритет производства: **Godot SpriteFrames / AnimatedSprite2D** на Android. Те же кадры/атласы позже переиспользуются в Phaser.

## Проекция

Side или ¾ side для всех боевых клипов (DEC-005). Фронтальные портреты UI — отдельно от боевого спрайта.

## Минимум героя (ориентир кадров)

| Клип | Кадры | Примечание |
|------|-------|------------|
| idle | 4–8 | loop |
| run | 6–10 | горизонтальное сближение |
| attack | 6–10 | basic |
| skill_1 | 6–12 | |
| skill_2 | 6–12 | |
| ultimate | 10–20 | читаемый telegraph |
| hit | 3–5 | |
| death | 6–10 | |
| victory | 6–10 | |
| personality | 8–16 | саркастичный характерный клип; низкий приоритет vs combat |

## Враги / боссы

Рядовой: idle, attack, hit, death + ключевые умения.  
Босс: + telegraph, phase_shift.

## Техлимиты Android (предложение до замеров)

- Atlas + сжатие; pooling VFX; лимит одновременных частиц.
- Пресеты quality: high / mid / low (6 ГБ RAM ориентир).
- Целевые FPS/RAM — **утвердить после первого профиля**, не обещать заранее.

VIS-00: анимации ещё не созданы; только концепт-иллюстрации.
