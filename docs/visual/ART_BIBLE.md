## 1. Направление

Высококачественная иллюстративная fantasy RPG: уральские горы, леса, реки, медь/бронза, резное дерево, камень, кожа, ткань, рунические формы, мистическое свечение. Культурные мотивы — осмысленно и по проверенным референсам; вымышленные орнаменты **не** выдавать за подлинный фольклор. Не копировать AFK Arena и чужие коммерческие UI.

**Тон:** ~60% эпики / ~40% иронии. Портреты серьёзные; юмор — в мимике, репликах, названиях умений и мелких гэговых деталях. Без мемного визуального шума и насмешек над культурой.

**Техника:** стилизованная 2D с 2.5D-ощущением (слои, параллакс, тени, частицы, масштаб). Только рисованные спрайты с покадровой анимацией (BATTLE-003 A). Вертикальный кадр.

## 4. UI-принципы

- Вертикаль; safe areas (notch / home indicator); touch ≥ 44–48 dp.
- Нижняя навигация на главных оболочках; валюты — верхний HUD.
- Состояния: empty / loading / error / success / locked на каждом экране каталога.
- Режим low-VFX; иконки 24/32/48.
- Карточки героев — рамка меди/камня, не «универсальный мобильный card UI».

## 5. Боевой кадр (DEC-005 — утверждено направление side-view)

- Вертикаль 9:16 UI; **камера строго сбоку**, fixed, без перспективы/изометрии.
- Игрок **слева** (5), враги **справа** (5); горизонтальная плоскость; лёгкий сдвиг рядов 2+3.
- Спрайты: side / ¾ side, рисованные 2D — не фронт, не 3D.
- Слои: far → mid → ground strip → characters → VFX → HUD.
- HUD верх: волна, таймер, пауза, x1/x2/x3, Auto.
- HUD низ: 5 портретов + энергия + ультимейты.
- Автобой + ручной ульт; читаемость важнее плотности VFX.
