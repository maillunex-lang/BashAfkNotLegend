## 1. Название стиля

**Bashkir Anime Sarcastic Fantasy 2D**

Качественная стилизованная anime-fantasy графика коллекционных мобильных AFK RPG.  
Ориентир **подачи** (читаемость, яркость, характер) — AFK Arena / аналоги; **запрещено** копировать персонажей, UI и арт чужих игр.

| Доля | Содержание |
|------|------------|
| ~60% | Эпическое фэнтези |
| ~40% | Саркастичный юмор (мимика, personality-клипы, реплики, детали костюма) |

Башкирская атмосфера: уральские пейзажи, орнаменты на экипировке/архитектуре/магии как **художественные мотивы**, не выдавать вымысел за канонический фольклор.

## 2. Что запрещено

- Фотореализм и реалистичные 3D-рендеры персонажей
- Изометрия / перспективный «вид в глубину» в бою (DEC-005)
- Фронтальный боевой спрайт как основной
- Дешёвый chibi / карикатурный кликбейт
- Мемный визуальный шум
- Башкирские и русские **личные** имена героев
- Копирование защищённых ассетов других проектов

## 3. Персонажи

| Параметр | Правило |
|----------|---------|
| Техника | Рисованная 2D Anime Fantasy |
| Пропорции | Стилизованные: выразительное лицо, слегка увеличенные голова/глаза, читаемый силуэт |
| Цвет | Яркий, насыщенный, гармоничный; фракционные акценты сохраняются |
| Деталь | Крупные формы брони/оружия; мелочь упрощать (смартфон) |
| Уникальность | Свой силуэт, палитра, характер на героя |
| Боевая проекция | Side / ¾ side |
| Портреты UI | Могут быть ближе к ¾ front для читаемости лица |

### Сарказм = personality-клипы (не ломают бой)

Примеры: танк поправляет щит → получает удар → недовольный взгляд; маг смотрит на посох после промаха; убийца отряхивает плащ после выхода из тени; целитель закатывает глаза; воин принимает пафосную позу и замечает, что никто не смотрит.

Клип `personality` — короткий, низкий приоритет vs combat actions.

## 4. Боевой кадр

Сохраняется DEC-005 side-view + уточнения стиля:

- 5 слева / 5 справа; fixed camera; без изометрии
- **Крупнее персонажи**, меньше пустого неба
- Ярче/насыщеннее фон Урала; многослойный параллакс
- Союзники/враги чётко разделены (сторона + лёгкий цветовой rim)
- VFX яркие, но не перекрывают спрайты и HUD
- Эталон кадра: `assets/source/concepts/battle/battle_concept_anime_sideview_e.jpg` → **review**
- `sideview_d` — superseded как стиль персонажей (layout side-view сохранён)

## 5. HUD

Премиум-фэнтези, но **чище**: меньше мелких рамок и текста.

| Зона | Элементы |
|------|----------|
| Верх | Волна, таймер, пауза, x1/x2/x3, Auto |
| Низ | 5 крупных портретов, полосы энергии ульта, ready-индикатор, tap = ручной ульт; состояния stun/death |
| Над юнитами | Компактный HP + важные статусы |
| Ввод | Touch ≥48 dp, safe areas, разные Android aspect |

## 6. Анимации (спека производства)

Обязательные клипы: `idle`, `run`, `attack`, `skill1`, `skill2`, `ultimate`, `hit`, `death`, `victory`, `personality`.  
Только отдельные кадры / 2D-слои / скелет — **не** одна статика с CSS-движением целого PNG.  
Рантайм: **Godot 4 Android**, бюджет RAM ≥6 ГБ устройств.

## 7. Враги и боссы

Тот же anime-fantasy язык. Мифологические боссы могут быть жутче/гротескнее героев, но в одной стилистике. Разнообразие силуэтов (не все гуманоиды). Fiction-флаги для Шурале/Убыр/Аждаха.

## 8. Единая система на все экраны

Стиль распространяется на: герои/враги, портреты/карточки, карта РБ, арены, меню, гача, инвентарь, гильдии, VIP/магазин, иконки, кнопки/панели/окна.

Для каждого типа ассета фиксировать: палитру, пропорции, размеры, свет, контур, LOD детализации, шаблон промпта — см. [DESIGN_TOKENS.json](DESIGN_TOKENS.json), [PROMPT_LIBRARY.md](PROMPT_LIBRARY.md).
