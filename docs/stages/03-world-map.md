# Этап 03 — Карта и кампания

Статус ROAD: `NOT_STARTED`  
Зависит от: 02

## Цель

Фэнтезийная карта на основе географии Башкортостана; главы/регионы; сюжетная печать; AFK-доход; боссы/экспедиции/башня. Сначала одна завершённая глава и регион.

## Утверждённые требования

MAP-001 C, MYTH-001 C, STORY-001 C, AFK-001 C, AFK-005 C  
Ссылки: [GAME.md](../../GAME.md) §2 этап 02/05, §4

## Зависимости

Боевой API; экономика AFK ([ECONOMY.md](../../ECONOMY.md)); политика ассетов карты (BQ-09).

## UX

- Карта регионов → узлы главы
- Диалоги с сарказмом (60/40)
- После боя — награды и прогресс AFK rate
- Активности в открытом регионе

## Модель данных

chapters, nodes, regions, player_campaign, afk_state, dialogues — CONTENT_SCHEMA §6.

## API / события

[API_CONTRACT.md](../../API_CONTRACT.md) §6

## Безопасность

Unlock только сервером; AFK по server time; идемпотентный claim.

## Edge cases

Повторный вход в узел; смена TZ; claim дважды; узел без боя; откат content_version.

## Производительность

Ленивая подгрузка тайлов/регионов; не грузить всю карту в RAM PWA.
