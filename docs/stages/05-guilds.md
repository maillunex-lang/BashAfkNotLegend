# Этап 05 — Гильдии и территориальные войны

Статус ROAD: `NOT_STARTED`  
Зависит от: 04 (BQ-07)

## Цель

Гильдии до 30 участников; база/магазин/боссы/исследования/экспедиции; карта районов; асинхронная оборона + окна атак; автоучастие; ИИ-гильдии с дипломатией без монополии карты.

## Утверждённые требования

GUILD-001 B … GUILD-005 D  
Ссылки: [GAME.md](../../GAME.md) §2 этап 07, [AI_PLAYERS.md](../../AI_PLAYERS.md) §7

## Зависимости

Онлайн/аккаунты; боевые снимки; планировщик ИИ; карта регионов (03).

## UX

- Создание/поиск/заявки/роли
- Гильд-хаб активностей
- Карта территорий + таймер войны
- Дипломатия: договоры со сроками
- Автоучастие в обороне/атаке по настройке

## Модель данных

guilds, guild_members (≤30), roles, guild_shop, territories, wars, war_actions, diplomacy_treaties, audit_log.

## API / события

[API_CONTRACT.md](../../API_CONTRACT.md) §8; WS `war.phase`, `guild.member`

## Безопасность

Атомарная смена владельца территории; проверка ролей; защита от double-claim; лимит 30 жёсткий.

## Edge cases

31-й участник; выход лидера; война на границе окна; истечение союза; AI overrun.

## Производительность

War resolution batch; не симулировать все обороны синхронно в одном HTTP.
