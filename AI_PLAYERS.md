# AI_PLAYERS.md — Поведение, память, чат, дипломатия

Утверждено: ONLINE-002 C, ONLINE-003 A, ONLINE-005 C, GUILD-005 D.  
**Запрет:** LLM в игровых чатах и «умных» репликах.

## 1. Цели системы

1. Наполнить мир виртуальными игроками с разным мастерством.
2. Участвовать в PvP, гильдиях, дипломатии без скрытых combat-читов.
3. Быть явно помеченными как ИИ.
4. Укладываться в бюджет CPU/RAM одного VPS (пакетная симуляция).

## 2. Профиль ИИ

| Поле | Описание |
|------|----------|
| `ai_id` | UUID |
| `display_name` | Имя + обязательный маркер «ИИ» в UI |
| `skill_tier` | `novice` \| `regular` \| `experienced` |
| `persona_tags` | Тон реплик (эпик/сарказм), без оскорблений культуры |
| `goals` | Краткосрочные/сезонные цели (кампания, арена, гильдия) |
| `memory` | Ограниченный лог отношений и событий |
| `resources_shadow` | Прогресс в тех же правилах экономики (сервер регулирует темп) |
| `guild_id?` | Членство в ИИ или смешанной гильдии по правилам |

`is_ai: true` во всех API-ответах сущностей.

## 3. Мастерство и честность (ONLINE-005 C)

- ИИ играют по тем же формулам боя и гачи.
- Сервер регулирует **скорость симуляции прогресса** и распределение силы популяции, но не даёт скрытый combat buff в рейтинговом PvP.
- Разные стратегии: агрессивный climb, казуальный AFK, гильд-фокус, коллекционер.
- Антиабуз: лимиты на частоту атак, отдельные политики матчмейкинга — BQ-06.

## 4. Память

```text
MemoryEntry { ts, type, subject_id, summary_key, weight, expires_at }
```

Лимиты (предложение до утверждения): N записей на ИИ, TTL, приоритет guild/war/chat relations.  
Память влияет на выбор цели и шаблон чата, не на «свободную генерацию текста».

## 5. Планировщик (пакетная симуляция)

Цикл воркера (интервал — BQ-08):

1. Выбрать батч ИИ по приоритету (онлайн-видимость, война, отставание целей).
2. Для каждого: обновить AFK-claim симуляции, назначить 0..K действий (узел, арена, гильд-донат, дипломатия).
3. Записать результаты транзакционно.
4. Поставить chat intents в очередь фраз.
5. Эмитить телеметрию: queue lag, actions/sec, errors.

Ограничения VPS: max concurrent AI ticks, circuit breaker при high CPU.

## 6. Чат: библиотека фраз (ONLINE-003 A)

```text
Phrase {
  id, locale, channel_types[],
  context_tags[],   // win, lose, greet, war_declare, sarcasm, ...
  persona_tags[],
  template,         // с плейсхолдерами из белого списка
  cooldown_group,
  weight
}
```

Правила:

- Тысячи реплик; контент версионируется.
- Контекст + persona → взвешенный выбор; антиповтор по cooldown_group.
- Фильтры спама: rate limit на ИИ и канал; не отвечать на каждое сообщение.
- Модерация библиотеки в админке; запрет токсичных шаблонов.
- Локализация — BQ-04.

## 7. ИИ-гильдии и дипломатия (GUILD-005 D)

Возможности:

- Создание/вступление в гильдии (лимит 30 как у игроков).
- Договоры, союзы, войны, конкуренция за районы.
- История дипломатии со сроками действия.

Ограничения монополии:

- Cap доли карты у ИИ-гильдий (BQ-07).
- Decay / сопротивление на сверхконцентрацию.
- Не блокировать игрокам ключевые стартовые районы бесконечно без окна отвоевания.

## 8. Наблюдаемость и админка

Админка (TECH-003 C): CRUD профилей, просмотр памяти, принудительная пауза ИИ, публикация phrase packs, дашборд распределения силы, аудит.

Телеметрия: % арены с ИИ, winrate по tier (без читов), жалобы на спам, доля территорий ИИ.

## 9. Тесты (минимум)

- Маркер `is_ai` всегда виден в API/UI контракте.
- Фраза не выбирается из LLM-пути (архитектурный assert: нет внешнего LLM client).
- Cooldown антиспама.
- ИИ не превышает guild 30.
- Детерминированный бой ИИ vs игрок при фиксированном seed.
- Нагрузочный тест планировщика на целевом батче (этап 04/07).
