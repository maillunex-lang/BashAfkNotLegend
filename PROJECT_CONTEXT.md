# PROJECT_CONTEXT.md

Краткий контекст для нового ИИ-агента. Детали — в связанных документах.

## Что это

**«Башкирия: Герои без легенд»** — вертикальная онлайн AFK Idle RPG на узнаваемой фэнтезийной карте Башкортостана. Тон: ~60% эпика / ~40% сарказма. Оригинальные фэнтезийные имена героев; география и мифологические мотивы допустимы при пометке авторского вымысла.

## Утверждённый стек (не менять)

| Слой | Решение |
|------|---------|
| Android | Godot 4, 2D-спрайты покадрово, 2.5D сцена — **текущий приоритет (DEC-003)** |
| iPhone | Отдельная React + Phaser **PWA** (не Godot Web) — **позже, только с разрешением** |
| Сервер | Go, PostgreSQL, Docker Compose, REST + WebSocket, авторитетный |
| Админка | React/TypeScript + визуальная студия |
| Порядок механик | По системам: герои → бои → карта → онлайн → гильдии → монетизация → релиз |
| Порядок сейчас | **Visual-first (VIS-00…)** на Android → механики Android → APK → (разрешение) PWA |
| Бой (визуал) | **2D side-view** (DEC-005): игрок слева, враги справа |
| Арт-стиль | **Bashkir Anime Sarcastic Fantasy 2D** (DEC-007); не фотореализм |

## Ключевые игровые правила

- Отряд 5 героев (2 впереди + 3 сзади), 5v5, гибридный автобой + ручные ультимейты, скорости x1/x2/x3, ограниченный skip.
- 6 фракций × 6 классов, 30 героев на релизе.
- AFK 24 ч база, VIP до 36–48 ч; резонанс 5 основных героев.
- ИИ-чат = **библиотека фраз, без LLM**; ИИ явно помечены.
- Гильдия ≤ **30** участников; ИИ-гильдии с дипломатией и союзами.
- VIP 0–15 с бесплатным прогрессом; без эксклюзивной боевой силы за деньги.

## Текущее состояние

- **VISUAL-APPROVAL-001 / DEC-012:** графика и анимации **V1 утверждены**. Не переделывать готовых героев бесконечно; ассеты заменяемы через `CharacterVisualDef`.
- Godot 2v2: `source_facing` / `desired_facing` / `battle_side`; логика (`CharacterData`) отделена от визуала; registry: braxor/nixara/stonekin/shadewolf.
- Генерация: герои → RIGHT, мобы/боссы → LEFT; L/R анимации через flip (+ особые случаи). Facing = позиция+цель (PvP-ready).
- Side-view layout (DEC-005) сохранён. Стиль **Bashkir Anime Sarcastic Fantasy 2D**.
- **PWA не разрабатывается**. Массовая генерация — мелкими партиями после рабочей facing-системы.
- Ветка работы: `cursor/braxor-facing-right-11ab`. VPS/деплой — только после явного разрешения.

## Инварианты безопасности

- Сервер авторитетен: бой, RNG, валюты, AFK, PvP, VIP, гильдии, платежи.
- Клиентские SDK генерируются из общих контрактов (`packages/contracts`).
- Секреты не в git; миграции версионируются; релизные APK/БД не удалять без разрешения.
- ИИ без LLM; культурные мотивы проверять, не выдавать вымысел за фольклор.
